# Heap.java
## Methods
- add() - will extend the list by 1 then add the element in the correct spot
- pop() - removes the root element of the list
- peek() - returns the value of the root element of the list
- size() - gets the size of the list then return it
- isEmpty() - returns false if there are no elements 

## Private Variables
- heap - a list of elements
- size - the size of the list/heap
